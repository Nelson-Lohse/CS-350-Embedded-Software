# CS-350

Summarize the project and what problem it was solving.

This project was all about creating a state machine to be used in an embedded system. The system it was made for was a thermostat that indicates whether the it was set to heat or cool and whether or not it was activily doing one of the two or not.

I feel like my final product was pretty good. I had a lot of problems with the LCD display throughout the course, but it ultimatly worked out pretty well. My code was simple and understandable and by teh end of the course I felt like I have a pretty good understanding of the key concepts.
